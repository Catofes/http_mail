# v0.1.1

修复“一键设置默认投递路由”的查询表名：`POST /transport_default/{domain_id}/1` 改为读取生产库中的 `my_networks`，与服务器列表接口一致。旧 Python 和 Go v0.1.0 使用了不存在的 `mynetworks`，导致接口在修改路由前返回 HTTP 500 / SQL Error。

- 无需修改数据库、创建兼容视图或转换数据；沿用现有配置。
- 保留原 API、权限、错误码以及事务内写入 `lmtp:unix:private/dovecot-lmtp` / `0default` 的行为。
- 测试夹具只创建真实的 `my_networks` 表，移除掩盖拼写错误的别名；同步 README。

已在仅有 `my_networks` 的临时 PostgreSQL 库中复现旧错误，并验证修正后的全部接口、默认路由写入和事务回滚。格式、go vet、单元测试及 race 检查通过。

发布附件与镜像提供 linux/amd64、linux/arm64。本次发布不部署生产服务。
